# 💱 Currency Converter

A simple and user-friendly **Currency Converter Web Application** built using **HTML, CSS, and JavaScript**.

The application allows users to select currencies, enter an amount, and convert the amount from one currency to another.

## 📌 Project Overview

The **Currency Converter** is a frontend web application designed to make currency conversion simple and easy to use.

Users can:

* Enter an amount
* Select a source currency
* Select a target currency
* Convert the amount
* View the converted currency value
* Use a simple and responsive interface

## ✨ Features

* 💱 Currency-to-currency conversion
* 🔢 Amount input
* 🌍 Multiple currency options
* 🔄 Easy currency selection
* ⚡ JavaScript-based conversion
* 🎨 Simple and clean user interface
* 📱 Responsive design
* 🧑‍💻 Beginner-friendly project structure

## ⚙️ How It Works

1. The user enters the amount to convert.
2. The user selects the **From Currency**.
3. The user selects the **To Currency**.
4. JavaScript processes the selected currencies and amount.
5. The converted value is displayed to the user.

## 🚀 How to Run the Project

### Method 1: Using VS Code Live Server

1. Clone the repository:

```bash
git clone https://github.com/prathmeshraut1014-tech/CurrencyConvertor.git
```

2. Open the project folder in **VS Code**.

3. Install the **Live Server** extension if you don't already have it.

4. Open:

```text
index.html
```

5. Right-click on `index.html`.

6. Select:

```text
Open with Live Server
```

7. The application will open in your browser.

### Method 2: Directly Open in Browser

You can also open `index.html` directly in a web browser.

## 🧪 Example

Suppose the user enters:

```text
Amount: 100
From: USD
To: INR
```

The application processes the selected currencies and displays the corresponding converted amount.

> Note: The conversion result depends on the exchange-rate data/API used by the application.
